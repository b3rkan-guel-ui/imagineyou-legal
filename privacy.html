2. Summary

Imagine You Uploader is a private tool used only by the operator with the operator's own YouTube channel "Imagine You". It does not offer any service to other people, has no user accounts, no advertising, no tracking and no cookies.

3. Data the app processes

  • Google login data of the operator: OAuth access and refresh token received through Google OAuth with the scopes youtube.upload, youtube.readonly and yt-analytics.readonly. Stored only on the operator's own computer.
  • Videos: animated videos and Shorts created by the app itself, uploaded to the operator's channel via the YouTube Data API (YouTube API Services).
  • Statistics of the operator's own videos: view, like and comment counts (YouTube Data API) and watch time, average view duration and subscribers gained (YouTube Analytics API), only for videos of the operator's own channel. Used to find out which topics, titles and thumbnails work best for future videos.
  • Public comments under the operator's own videos: the comment text (shortened) and its like count, used to collect viewer wishes for new topics. User names, channel IDs and profile data of commenters are not stored.

Legal basis: Art. 6(1)(f) GDPR (legitimate interest in running and improving the operator's own YouTube channel). Data is not sold and not shared with anyone. To summarise statistics and comments, the text is processed by an AI model (Anthropic Claude) on behalf of the operator; no personal data of commenters is included.

4. YouTube API Services

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Processing on Google's side is governed by the Google Privacy Policy. Access granted to this app can be revoked at any time on the Google security settings page.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Retention

Tokens are kept until access is revoked or they expire; a revoked token is deleted from the operator's computer on the next run. Statistics and comment texts are replaced on every run and never kept longer than 30 days. Videos are kept locally for at most 12 production runs. Deletion requests can be sent to info.berkan.guel@web.de and are handled within 7 days.

6. This website

These pages are hosted on GitHub Pages (GitHub, Inc., USA). When you open them, GitHub processes technical data such as your IP address to deliver the page and keep the service secure. See the GitHub Privacy Statement. The pages load no external fonts, trackers or scripts. The light/dark switch saves your choice only in your own browser.

7. Your rights

You have the right to access, rectification, erasure, restriction of processing, data portability and objection (Art. 15–21 GDPR). Contact info.berkan.guel@web.de. You may also complain to a data protection supervisory authority.
